
# ShopEase - UI/UX Case Study

## Project Overview
ShopEase is a UI/UX case study for an e-commerce shopping application.

The project focuses on creating a simple, user-friendly and responsive shopping experience.

## Project Objectives
- Improve product discovery
- Simplify navigation
- Create a clear product presentation
- Improve shopping cart interactions
- Design a simple checkout experience
